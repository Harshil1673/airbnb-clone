# Airbnb Clone

A pixel-accurate recreation of an Airbnb-style property listing interface, built as a frontend project.

## 🚀 Features

- Responsive Airbnb-style property listing page
- Property image gallery
- Photo Tour with categorized photos
- Interactive photo lightbox
- Image navigation with previous/next controls
- Keyboard navigation support
- Amenities section
- Reviews section
- Location/map section
- Host information
- Booking/reservation card
- Responsive layout for different screen sizes
- Local image and UI assets
- Smooth transitions and interactive UI effects

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- CSS / CSS Modules
- JavaScript / TypeScript
